# Tasarım kartları

Uygulamanın ekran tasarımları. Her `.dc.html` dosyası tek bir ekranı ya da durumu gösteren statik bir tasarım kartıdır. Kartlar bir tasarım aracında hazırlandı; tarayıcıda doğrudan çalışan sayfalar değildir, renk değerleri ve yerleşim için referans olarak kullanılır.

| Dosya | İçerik |
|---|---|
| `Main`, `OzetMasaustu`, `OzetMobilKoyu`, `OzetDurum`, `Ozet*` | Özet ekranı ve durumları |
| `IslemlerMobil`, `IslemlerMasaustu`, `IslemlerFiltre`, `IslemlerSil`, `Islemler*` | İşlemler › Kayıtlar |
| `SabitMobil`, `SabitBos` | İşlemler › Sabit |
| `IslemEkle`, `IslemEkle*`, `IslemSabitDuzenle` | İşlem ekle/düzenle formu |
| `KategorilerMobil`, `KategoriDuzenle`, `KategoriSil` | Kategoriler |
| `AyarlarMobil`, `AyarlarGecersiz`, `GeriYukle`, `TumunuSil*` | Ayarlar, geri yükleme, tüm verileri sil |
| `Bilesenler`, `BilesenlerKoyu` | Bileşenler (açık ve koyu tema) |
| `canvas.json` | Kartların tuval üzerindeki yerleşimi |

Metin karşılığı: [Tasarım belgesi](../tasarim.md).
